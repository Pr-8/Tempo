# Tempo Database Schema

Tempo uses PostgreSQL for data persistence. The schema is designed to support both deterministic scheduling and conversational AI.

## Table: `tasks`
The central source of truth for all user requirements.

| Column | Type | Description |
| :--- | :--- | :--- |
| `id` | UUID | Primary Key. |
| `title` | String | User-defined title. |
| `course` | String | Optional course association. |
| `estimated_hours` | Float | Total time required. |
| `deadline` | Date | Hard constraint for the solver. |
| `priority` | String | `high`, `medium`, `low`. Influences solver objective. |
| `status` | String | `pending`, `complete`, `failed`. |
| `source` | String | `manual`, `syllabus`, `chat`. |
| `is_fixed` | Boolean | If `true`, this is an "Event" with a fixed time. |
| `fixed_start` | DateTime | Start time for fixed events. |
| `fixed_end` | DateTime | End time for fixed events. |

## Table: `scheduled_sessions`
Concrete time blocks generated by the solver.

| Column | Type | Description |
| :--- | :--- | :--- |
| `id` | UUID | Primary Key. |
| `task_id` | UUID | Foreign Key to `tasks.id`. |
| `start_time` | DateTime | Calculated by the solver. |
| `end_time` | DateTime | Calculated by the solver. |
| `status` | String | `pending`, `complete`, `failed`. |

## Table: `user_preferences`
Configuration for the solver's hard and soft constraints.

| Column | Type | Description |
| :--- | :--- | :--- |
| `available_days` | String | Comma-separated (e.g., `mon,tue,wed`). |
| `day_start` | String | e.g., `09:00`. |
| `day_end` | String | e.g., `18:00`. |
| `max_sessions_per_day` | Integer | Soft constraint for burnout prevention. |
| `min_break_minutes` | Integer | Gap between sessions. |
| `schedule_dirty` | Boolean | Flag to trigger regeneration. |
| `last_schedule_explanation` | String | Stored narrative generated by Gemini. |

## Table: `chat_messages`
Historical record of conversational interactions.

| Column | Type | Description |
| :--- | :--- | :--- |
| `role` | String | `user`, `assistant`, `tool`. |
| `content` | String | The message text. |

## Table: `user_memories`
Persistent facts extracted from conversations (Phase 2).

| Column | Type | Description |
| :--- | :--- | :--- |
| `content` | String | e.g., "User prefers working late". |
| `memory_type` | String | `constraint`, `preference`, `context`. |
